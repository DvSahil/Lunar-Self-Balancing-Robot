# data/

Put **your own** measurements here. Nothing in this folder ships with results on purpose.

* `tuning_log.csv` — one row per tuning attempt (copy `tuning_log_template.csv`)
* `experiment_log.md` — validation experiments (see doc 5, step 7)
* `runs/` — raw CSV logs from `tools/log_serial.py` and the plots from `tools/plot_log.py`
